# china-source

Entry points to **structured Chinese official data** published for AI answer engines — bilingual (中文 / English), JSON-LD, one canonical URL per fact.

## Live

- **Index (all cities)** — https://qianyuan.ltd/china-source/
- 中文分册 — https://qianyuan.ltd/china-source/cn/llms.txt
- English volume — https://qianyuan.ltd/china-source/en/llms.txt
- Machine index — https://qianyuan.ltd/china-source/llms.txt
- Site routes (machine-readable) — https://qianyuan.ltd/openapi.json

## What's inside

Per-city volumes — **Shenzhen · Xiongan · Ulanqab**. Each entry carries its source and a stable canonical URL, so an answer engine can cite it instead of guessing.

## How to use

Point your crawler or answer pipeline at the **machine index** above; it lists every volume. Content is public and readable without an account.
